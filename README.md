# House of the Dead: Overkill Tweaks

## Features

- Upscale the rendering resolution of the game up to 8k (6x the original fixed 720p internal resolution).
- Fix the broken cutscene post-processing effects that occur when upscaling the rendering resolution.
- Optionally disable the depth of field effect that causes the broken cutscene post-process effects, if you prefer a sharper look.
- Enable or disable crosshairs without needing to replace game level files (WIP, not working in this release). This is great for PC light guns like Sinden, Retro Shooter, and others.
- Includes fix for missing zombie torsos (no setting in the GUI to turn this on/off, it's automatically applied)
- Also works for Typing of the Dead
